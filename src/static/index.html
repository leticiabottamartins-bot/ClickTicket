Usuários

Método Rota Parâmetros Descrição Exemplo de Retorno (sucesso)
GET /usuarios Nenhum Lista todos os usuários cadastrados (com o nome do gênero preferido) 
[{"id":1,"nome":"Ana Souza","cpf":"111.111.111-11","ano_nasc":2005,"gosto":"MPB","email":"ana@email.com"}]
GET /usuarios/:id Rota: id (inteiro) Retorna um usuário pelo ID 
{"id":1,"nome":"Ana Souza","cpf":"111.111.111-11","ano_nasc":2005,"gosto":"MPB","email":"ana@email.com"}
POST /usuarios Body (JSON):
nome (string, mín. 2 caracteres)
cpf (string, formato 000.000.000-00)
ano_nasc (int, entre 1900 e o ano atual)
gosto (int — ID de gênero musical existente, obrigatório na prática)
email (string, precisa conter "@" e ".com")
senha (string) 		Cadastra um novo usuário. Valida formato de CPF/e-mail, unicidade de CPF e existência do gênero musical informado 
{"msg":"Uhull, bem vindo!","usuario":{"id":6,"nome":"Ana Souza","cpf":"111.111.111-11","ano_nasc":2005,"gosto":"MPB","email":"ana@email.com"}}
PUT /usuarios/:id Rota: id (inteiro)
Body (JSON): nome, ano_nasc, gosto, email, senha (todos obrigatórios) 		Edita um usuário existente. Mesmas validações do POST 
{"msg":"Usuário editado com sucesso!","usuario":{"id":1,"nome":"Ana Souza","cpf":"111.111.111-11","ano_nasc":2005,"gosto":"MPB","email":"ana@email.com"}}
DELETE /usuarios/:id Rota: id (inteiro) Remove um usuário do banco de dados 
{"msg":"Usuário deletado com sucesso!"}
GET /usuarios/:id/recomendacoes Rota: id (inteiro) Recomenda shows com base no gênero musical preferido do usuário 
{"gosto":"MPB","shows":[{"id":1,"nome":"Festival de Música Brasileira","data":"2026-10-10T23:00:00.000Z","local":"Arena São Carlos","endereco":"Av. Trabalhador São-Carlense, 100","genero":"MPB","atracoes":[{"id":4,"nome":"Gilberto Gil"}]}]}

GET /shows/faturamento/:id Rota: id (inteiro, ID do show) Retorna o faturamento total (soma dos preços dos ingressos vendidos) de um show 
{"show":"Festival de Música Brasileira","faturamento":"50.00"}
GET /shows/local/:id Rota: id (inteiro, ID do local) Lista os shows cadastrados em um determinado local (colunas cruas da tabela show) 
[{"id":1,"nome":"Festival de Música Brasileira","data":"2026-10-10T23:00:00.000Z","local_id":1}]
GET /shows/:id Rota: id (inteiro) Retorna um show pelo ID, com o nome do local 
{"id":1,"nome":"Festival de Música Brasileira","data":"2026-10-10T23:00:00.000Z","local":"Arena São Carlos"}
POST /shows Body (JSON):
nome (string)
data (string, formato DD/MM/AAAA)
horario (string, formato HH:MM)
local_id (int, ID de local existente) 		Cadastra um novo show. Data/horário devem ser no futuro e o local não pode já ter outro show marcado no mesmo horário 
{"msg":"Show adicionado","show":{"id":6,"nome":"Rock in Rio","data":"2026-12-04T22:30:00.000Z","local":"Arena São Carlos"}}
PUT /shows/:id Rota: id (inteiro)
Body (JSON): mesmos campos do POST — nome, data (DD/MM/AAAA), horario (HH:MM), local_id 		Edita um show existente. Mesmas validações do POST 
{"msg":"Show editado","show":{"id":1,"nome":"Rock in Rio","data":"2026-06-04T22:30:00.000Z","local":"Arena São Carlos"}}
DELETE /shows/:id Rota: id (inteiro) Remove um show do banco de dados 
{"msg":"Show deletado!"}

Ingressos

Método Rota Parâmetros Descrição Exemplo de Retorno (sucesso)
GET /ingressos Nenhum Lista todos os ingressos, com dados do usuário, show, tipo e preço do lote 
[{"id":1,"usuario_id":1,"nome_usuario":"Ana Souza","nome_show":"Festival de Música Brasileira","lote_id":1,"tipo":"Pista","preco":"50.00"}]
GET /ingressos/:id Rota: id (inteiro) Retorna um ingresso pelo ID, com dados do usuário, show, tipo e preço do lote 
{"id":1,"usuario_id":1,"nome_usuario":"Ana Souza","nome_show":"Festival de Música Brasileira","lote_id":1,"tipo":"Pista","preco":"50.00"}
POST /ingressos Body (JSON):
usuario_id (int, ID de usuário existente)
lote_id (int, ID de lote com ingressos disponíveis) 		Vende um ingresso: valida usuário, decrementa a disponibilidade do lote e cria o registro (operação transacional) 
{"msg":"Ingresso vendido com sucesso","ingresso":{"id":8,"usuario_id":1,"nome_usuario":"Ana Souza","nome_show":"Festival de Música Brasileira","lote_id":1,"tipo":"Pista","preco":"50.00"}}
PUT /ingressos/:id Rota: id (inteiro)
Body (JSON): usuario_id (int, ID de usuário existente) 		Transfere um ingresso para outro usuário (não altera o lote) 
{"msg":"Ingresso editado com sucesso","ingresso":{"id":1,"usuario_id":2,"nome_usuario":"Lucas Oliveira","nome_show":"Festival de Música Brasileira","lote_id":1,"tipo":"Pista","preco":"50.00"}}
DELETE /ingressos/:id Rota: id (inteiro) Cancela um ingresso e devolve a vaga para a disponibilidade do lote 
{"msg":"Ingresso excluído com sucesso"}

Shows-Atrações

Método Rota Parâmetros Descrição Exemplo de Retorno (sucesso)
GET /showsAtracoes Nenhum Lista todos os shows que possuem atrações, agrupando as atrações de cada show 
[{"id_show":1,"nome_show":"Festival de Música Brasileira","atracoes":[{"id":4,"nome":"Gilberto Gil"},{"id":5,"nome":"Jão"}]}]
GET /showsAtracoes/:id Rota: id (inteiro, ID do show) Retorna todas as atrações de um show pelo ID do show 
{"id":1,"nome":"Festival de Música Brasileira","atracoes":[{"id":4,"nome":"Gilberto Gil"},{"id":5,"nome":"Jão"}]}
POST /showsAtracoes Body (JSON):
showId (int, ID de show existente)
atracaoId (int, ID de atração) 		Vincula uma atração a um show. Valida se a atração já não está em outro show na mesma data/horário e se o vínculo já não existe 
{"msg":"Atrações adicionadas ao show!","ID_show":1,"nome_show":"Festival de Música Brasileira","ID_atracao":9,"nome_atracao":"Legião Urbana"}
PUT /showsAtracoes/:showId/:atracaoIdVelha Rota: showId, atracaoIdVelha (inteiros)
Body (JSON): atracaoId (int, nova atração) 		Substitui, em um show, a atração antiga pela nova informada 
{"msg":"Atração do show editada com sucesso!","ID_show":1,"nome_show":"Festival de Música Brasileira","ID_atracao":9,"nome_atracao":"Legião Urbana"}
DELETE /showsAtracoes/:showId/:atracaoId Rota: showId, atracaoId (inteiros) Remove o vínculo entre um show e uma atração 
{"msg":"Atração cancelada no show!"}

Lotes de Ingresso

Método Rota Parâmetros Descrição Exemplo de Retorno (sucesso)
GET /lotes Nenhum Lista todos os lotes de ingresso, com o nome do show 
[{"show_id":1,"id":1,"nome_show":"Festival de Música Brasileira","tipo":"Pista","preco":"50.00","quantidade":1000,"disponivel":1000}]
GET /lotes/faixadepreco Query:
minimo (número, ≥ 0)
maximo (número) 		Lista lotes cujo preço está entre minimo e maximo (inclusive) 
[{"id":1,"show_id":1,"nome_show":"Festival de Música Brasileira","tipo":"Pista","preco":"50.00","quantidade":1000}]
GET /lotes/:id Rota: id (inteiro) Retorna um lote de ingresso pelo ID 
{"show_id":1,"id":1,"nome_show":"Festival de Música Brasileira","tipo":"Pista","preco":"50.00","quantidade":1000,"disponivel":1000}
POST /lotes Body (JSON):
show_id (int, ID de show existente)
tipo (string, ex. "Pista", "VIP")
preco (número, ≥ 0)
quantidade (int, ≥ 0) 		Cadastra um novo lote de ingressos para um show, validando se a soma das quantidades não ultrapassa a capacidade do local. disponivel é inicializado igual a quantidade 
{"id_lote":11,"id_show":1,"nome":"Festival de Música Brasileira","tipo":"Camarote","preco":150,"quantidade_ingressos":50,"disponiveis":50}
PUT /lotes/:id Rota: id (inteiro)
Body (JSON): show_id, tipo, preco, quantidade (mesmas regras do POST) 		Edita um lote existente. A nova quantidade não pode ser menor que o número de ingressos já vendidos desse lote, e a capacidade do local não pode ser excedida. disponivel é recalculado como quantidade - vendidos 
{"msg":"Uhull, lote de ingressos atualizado!","id_lote":1,"id_show":1,"nome":"Festival de Música Brasileira","tipo":"Pista","preco":55,"quantidade_ingressos":1000,"disponiveis":999}
